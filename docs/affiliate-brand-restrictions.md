- Нельзя изменять предоставленный текст (можно только сокращать)
- Non-Commissionable: подарочные карты, матрасы, мебель
- Payment: ежемесячно, только после достижения минимального порога



## Формула заглушки логотипа — стандарт с 31 августа 2026

Для магазинов, где Google Favicons API не находит реальную иконку (проверять всегда перед сохранением — если видна серая иконка-глобус, значит, сервис не проиндексировал сайт) — использовать:

```
https://ui-avatars.com/api/?name={БУКВА}&background=FBFAF7&color=B8291B&bold=true&size=128&rounded=true&font-size=0.7
```

Где `{БУКВА}` — первая буква названия магазина. Даёт светлый фон (`paper`) + акцентную букву (`coupon-dark`) — гармонично вписывается в общий дизайн сайта, лучше, чем прежний вариант через `placehold.co` (тёмный фон, менее гибкая стилизация).

⚠️ Домен `ui-avatars.com` должен быть добавлен в `next.config.ts` → `images.remotePatterns`.

## Известные технические ограничения

- **Google Favicons API** не всегда имеет иконку для небольших/нишевых брендов — возвращает обобщённую серую заглушку-глобус. Проверять вручную перед сохранением магазина.
- **`placehold.co`** отдаёт SVG по умолчанию — требует `dangerouslyAllowSVG: true` в `next.config.ts`, иначе Next.js `<Image>` блокирует показ на публичных страницах (хотя в админке через обычный `<img>` всё равно видно — источник путаницы при диагностике).
- Автоматическое обновление логотипа при смене Website URL работает только при **создании** нового магазина. При **редактировании** существующего — `isLogoTouched` изначально `true`, нужно явно нажать "Change logo manually" → "Reset to automatic favicon".
- При странных, необъяснимых 404 на localhost (особенно после серии правок в разных файлах) — первым делом пробовать `rm -rf .next` и перезапуск dev-сервера, прежде чем искать баг в коде.
